Hamiltonian Paths & Cycles

A Hamiltonian path visits every vertex of a graph exactly once, while a Hamiltonian cycle is a closed loop visiting every vertex exactly once before returning to the start. Determining Hamiltonicity is an NP-complete problem.

Mandatory Properties, Necessary Conditions & Sufficient Theorems

1

Mandatory Connectedness

Connectedness is mandatory for any graph containing a Hamiltonian path or cycle. If a graph is disconnected, components cannot be spanned continuously across all vertices.

G must be connected to possess a Hamiltonian cycle or path.
2

Connected Components Theorem (Vertex Subsets)

If G is Hamiltonian, then for every nonempty proper subset S ⊂ V(G), the number of connected components of G - S is at most |S|.

c(G - S) ≤ |S|
Example: Deleting vertex subsets from a cycle results in limited broken paths.
3

Minimum-Degree Condition

If a simple graph G with n ≥ 3 vertices is Hamiltonian, then every vertex has degree at least two: δ(G) ≥ 2. Vertices of degree 0 or 1 rule out cycles.

δ(G) ≥ 2
4

Dirac's Theorem (Sufficient)

Let G be a simple graph with n ≥ 3 vertices. If deg(v) ≥ n/2 for every v ∈ V(G), then G is Hamiltonian.

deg(v) ≥ n/2 for every v ⟹ Hamiltonian
5

Ore's Theorem (Sufficient)

Let G be a simple graph with n ≥ 3 vertices. If deg(u) + deg(v) ≥ n for every pair of distinct nonadjacent vertices u, v, then G is Hamiltonian.

deg(u) + deg(v) ≥ n for every pair of distinct nonadjacent vertices u, v ⟹ Hamiltonian
